# 聊天优先工作界面（Chat-First Workspace）使用说明

Conflux 打开即进入聊天工作界面：左侧是聊天室与最近会话，主区是当前目标的对话，助手配置与运行实例集中在「助手」页。本文描述用户可观察的行为、版本边界与验收状态。

## 界面导览

```
┌────────────┬──────────────────────────────┬─────────────┐
│ 聊天        │ 当前房间名  [聊天|图谱]       │ 成员 / 任务  │
│ 图谱        │                  [查看全局]   │ 详情（可收起）│
│ 活动记录    │                              │             │
│ 助手        │      消息、任务与结果         │             │
│            │                              │             │
│ 聊天室   ＋ │ @成员 输入任务        [发送]  │             │
│ 最近会话    │                              │             │
│ 在线    设置 │                              │             │
└────────────┴──────────────────────────────┴─────────────┘
```

- **默认与恢复**：每次启动进入聊天。房间列表加载成功后恢复上次房间（id + 创建时间都匹配才算同一个房间）；失败回退到最近更新的房间。列表加载失败显示错误与重试，不会误报「没有房间」。
- **草稿**：每个房间/单聊的草稿互相独立，切走再回来不丢；发送成功只清空发送时那份内容，发送期间继续输入的文字保留。
- **房间聊天**：`@成员` 定向（按完整会话 id，重名成员在候选里用 id 片段区分），不 @ 则广播给全部成员；成员离开后定向目标失效会阻止发送并要求重选，绝不静默扩大为广播。输入法组合输入时 Enter 不会误发。
- **单聊**：点最近会话即进入与该会话的单聊，走消息问答原路径；不属于任何房间也可单聊。
- **房间图谱**：房间头部 [聊天|图谱] 是同一房间的两个视图，切换不动草稿；房间图只含成员与成员之间的真实通道，「查看全局图谱」可往返，视口与拖拽位置按范围记忆。
- **活动记录**：全局消息流。外部会话之间的通道保留边视图；涉及 Web 控制台的条目点击后进入工作界面对应单聊。
- **助手**：编码助手（CLI 启动配置 + 运行实例 + 已接入会话）与模型助手（独立 API 对话）同页分类管理。同名不同类、同 id 不同类的对象永不混淆；停止/恢复实例始终以服务端校验为准。模型助手为独立对话，本批不提供加入聊天室的能力。

## 尺寸与键盘

- ≥1280px：三栏（导航 248px / 主区 / 详情 320px 可收起）。
- 768–1279px：详情为覆盖抽屉。
- <768px：导航与详情互斥抽屉；Esc 关闭抽屉并归还焦点。
- 320px 宽仍可看到并操作发送按钮，无横向滚动。

## 版本边界

- 本批（P1–P4）不改变后端协议与数据库结构；旧数据原样读取。
- 不包含：模型助手加入多方聊天室（独立设计项目）、自动编排、自动建房/唤醒/发送。
- 发送身份默认 Web 控制台；房间内可选择成员身份发起。

## 常见问题

- **为什么恢复的房间不对？** 恢复要求 id 与创建时间同时匹配；房间被删除重建后视为新房间，回退到最近更新的房间。
- **@ 了成员却发不出去？** 目标成员已离开房间：重新 @ 或显式清除目标改为广播。
- **图谱为什么是空的？** 房间图显示全部成员（含离线）；成员尚未在图谱出现时详情栏会列出「暂无法加载的成员」。
